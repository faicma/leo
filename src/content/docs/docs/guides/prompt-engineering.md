## 核心原则

1. **说清楚背景**：你是谁、在什么场景下、给谁用
2. **明确任务**：要它做什么、不要做什么
3. **给出格式**：希望输出长什么样，最好给个例子
4. **迭代改进**：第一次不满意很正常，追问和修正

## 一个好 Prompt 的结构

```text
【角色】你是一位 experienced 的生物老师
【任务】帮我用生活化的例子解释细胞呼吸
【受众】我是高一学生，刚学完光合作用
【格式】用 3 个要点 + 1 个类比来解释，控制在 300 字内
```

## 常用技巧

- Few-shot：给 2-3 个输入输出示例
- 思维链：让它"一步一步思考"
- 让它先复述任务再执行
