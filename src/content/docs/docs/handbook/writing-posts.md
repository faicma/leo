## 方式一：Git 投稿（推荐）

1. Fork 仓库 `faicma/leo`
2. 在 `src/content/posts/` 下新建 Markdown 文件：

```markdown
---
title: 文章标题
published: 2026-10-26
description: 一句话摘要
tags: ["标签1", "标签2"]
category: 分类
---

正文从这里开始……
```

3. 提交 PR，审核通过后自动上线

## 方式二：发给管理员

把 Markdown 文件（或纯文字）发给 Club 的内容负责人，由管理员代发。

## 写作建议

- 标题具体一点，别用"随记"这种
- 开头一段讲清楚"读完你能得到什么"
- 代码块记得标语言
